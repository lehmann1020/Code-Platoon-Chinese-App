# Component: Match card
A button showing either a hanzi (left column) or pinyin (right column).
States: default · hover (lift) · focus-visible · selected (ring, `aria-pressed=true`) · wrong (red + shake) · exploding (particles) · gone.
Props: `kind` ("hanzi" | "pinyin"), `text`, `state`, `onSelect`.
Accessible name: "Hanzi: 你好" / "Pinyin: nǐ hǎo".
